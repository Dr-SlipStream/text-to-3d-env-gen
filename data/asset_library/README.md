# Asset Library

3D models live here, organised by category. **Not committed to git** — the
binaries are large and freely re-downloadable.

Populated in week 2 via `scripts/download_assets.py`.

Planned structure:

```
asset_library/
  building/
  prop/
  vegetation/
  rock/
  structure/
  light_source/
  manifest.json     # name, category, path, tags, bounding radius per asset
```

## Sources (all free, license-clear)

- **Kenney.nl** — CC0 (public domain, no attribution required), game-ready low-poly packs
- **Poly Pizza** — CC0 / CC-BY models
- **OpenGameArt** — mixed licenses, check each asset

CC0 is preferred so there are no attribution obligations in the final report.
